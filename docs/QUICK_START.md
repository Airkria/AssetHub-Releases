# AssetHub · 快速开始

**连接已有文件夹，开始浏览和整理素材。**

适用：**2.0.0-alpha.5 · Windows 10/11 x64**

[下载安装包](https://github.com/Airkria/AssetHub-Releases/releases/download/v2.0.0-alpha.5/AssetHub_2.0.0-alpha.5_x64-setup.exe) · [反馈问题](https://github.com/Airkria/AssetHub-Releases/issues/new/choose)

## 01 准备开始

下载并安装 AssetHub，再准备一个小素材文件夹。第一次建议用几张图片的副本试试。

![准备流程：下载安装包，完成安装，打开 AssetHub](images/setup-overview.svg)

<details>
<summary>展开 · 下载与安装步骤</summary>

1. 点击上方 **「下载安装包」**，保存 `.exe` 文件。也可到[版本下载页](https://github.com/Airkria/AssetHub-Releases/releases/tag/v2.0.0-alpha.5)的 Assets（附件）中下载同名安装包。
2. 双击 `AssetHub_2.0.0-alpha.5_x64-setup.exe`，按提示安装并打开。
3. 准备一个本机小文件夹，放入几张图片副本，稍后连接它。

缺少 WebView2 时，安装器会联网下载。若系统提示未知发布者，请先核对下载来源；当前安装包没有 Windows 发布者证书签名。

</details>

## 02 添加素材库

**选择工作范畴 → 连接文件夹 → 扫描。** 完成后，你的素材就会出现在软件中。

素材留在原目录；左侧的**板块**，就是进入对应文件夹的浏览入口。

![连接素材文件夹：本例只启用「灵感图片」，为它选择自己的文件夹](images/02-connect-folder.jpg)

*示例：先连接一个「灵感图片」板块，其余按需添加。*

<details>
<summary>展开 · 添加第一个素材库</summary>

### 第一步：选工作范畴

首次打开后，点击 **「设计相关」→「下一步」**。也可选择更接近你用途的方向；不确定时选「自由探索」。

![选择工作范畴，为素材库使用对应的布局预设](images/01-choose-work.jpg)

### 第二步：选文件夹

只保留「灵感图片」，点击 **「选择文件夹」**，在系统窗口中选中准备好的目录并确认。回到引导后，检查路径，再点 **「下一步」**。

已经选择过目录时，按钮显示「更换」。如果启用多个板块，需要分别选择目录。

### 第三步：扫描并开始

保留勾选 **「完成后扫描第一个新板块」**，点击 **「完成并开始使用」**，等待素材卡片出现。

![确认目录后，点击「完成并开始使用」](images/03-start-scan.jpg)

没有自动扫描？选中左侧板块，打开 **「设置 → 扫描索引 → 扫描当前板块」**。其余新板块也需切换后分别扫描。

</details>

## 03 浏览与整理

**搜索找素材，标签做整理，打开位置回到原文件。** 点击卡片，可在右侧查看详情。

![素材浏览界面：左侧选择板块，中间浏览卡片，右上角搜索，右侧查看选中素材的详情](images/04-browse-library.jpg)

*图中尚未选中素材；标签和文件位置操作在选中后的详情中。*

<details>
<summary>展开 · 搜索、标签与文件定位</summary>

| 你想做什么 | 操作 |
| --- | --- |
| 找素材 | 在右上角 **「搜索名称或标签…」** 输入名称的一部分或标签。清空即可恢复列表。 |
| 添加标签 | 点击卡片，在右侧 **「添加标签」** 输入内容，按 Enter 或点加号；确认「标注已保存」。 |
| 快速查看视频／GIF | 鼠标在卡片或详情预览区停留片刻，再左右移动查看画面；点击视频预览或「播放」开始播放，点「停止」回到预览。 |
| 找到原文件 | 选中素材，在右侧点击 **「打开文件位置」**。 |
| 换目录或加板块 | 打开 **「设置 → 板块」**，调整目录或点击「打开新手引导」。 |

![设置中的板块配置和「打开新手引导」入口](images/05-reopen-guide.jpg)

重新引导会追加板块，保留已有板块和全局设置。连接和扫描不搬动素材；**重命名、删除会影响原文件**。

</details>

## 04 常见问答

找不到文件、预览打不开或需要更新？展开对应问题即可。

<details>
<summary>文件明明在文件夹里，为什么看不到？</summary>

先清空搜索、取消其他筛选。有 **「推荐类型 · 切换」** 按钮时，点击切换到 **「全部文件」**。推荐类型只影响显示，不会删除其他类型的索引；新增文件后重新扫描当前板块。

</details>

<details>
<summary>所有文件都能直接预览吗？</summary>

不能。视频播放取决于编码，部分模型和设计源文件需要外部软件打开。视频／GIF 支持横向滑动预览，但不保证所有编码和动图都可解码。

「设置 → 预览设置」可调整视频预览大小上限，默认 1024 MiB，也可选择不限制。此值只是建议，阈值以内也不保证预览成功；超限视频使用外部播放器。

</details>

<details>
<summary>怎么更新？遇到问题在哪里反馈？</summary>

**更新：**「设置 → 关于 → 检查更新」，按提示下载、安装并重启。先完成保存、扫描和模型转换。

**反馈：**到 [GitHub Issues](https://github.com/Airkria/AssetHub-Releases/issues/new/choose) 提交**版本、操作步骤、预期/实际结果和截图**。公开截图请去除私人路径、个人信息和保密素材；私密问题发送至 **airkria915793472@gmail.com**。

</details>

<details>
<summary>使用共享库或 NAS，需要注意什么？</summary>

先在 Windows 文件资源管理器中确认目录可访问。多人同时编辑共享库标注的冲突处理尚未完成，建议先使用个人库。保存失败时，修改仅保留在本次运行中，恢复连接并重试成功后再退出。

</details>

<details>
<summary>截图中的「模拟环境」是什么？</summary>

截图来自实际桌面应用的隔离模拟环境，使用生成的示例素材。图中的测试路径无需照抄，正常安装后不会显示模拟提示。

这些截图不代表真实新机安装、跨版本升级或 NAS 大库验收已经完成。

</details>
